# 🍸 GSAP Cocktail Website

A stunning scroll-driven cocktail website built with React, GSAP, Tailwind CSS, and Vite. This project delivers immersive animations, cinematic storytelling, and a modern responsive UI powered by advanced GSAP techniques.

---

## 🤖 Introduction

Build and deploy a stunning GSAP-powered cocktail website using React and Tailwind CSS — a modern, scroll-driven experience packed with advanced animations.

Bring your design to life with:

- Dynamic SplitText reveals
- Smooth parallax scrolling
- Scroll-triggered effects using GSAP ScrollTrigger
- Pinned section animations
- Scroll-synced video playback
- Scroll-based image masking
- Custom animated carousel
- Seamless timeline animations
- Fully responsive design across all devices

This project showcases how powerful motion design can transform a modern frontend experience.

# ⚙️ Tech Stack

## 🚀 GSAP
GSAP is a powerful JavaScript animation library used to create dynamic, scroll-driven visuals.

### Features Used:
- SplitText animations
- ScrollTrigger timeline control
- Parallax scrolling
- Pinned sections
- Scroll-synced video playback
- Image masking effects
- Multi-section timeline animations
- Custom animated carousel

---

## ⚛️ React
React provides the component-based architecture for building interactive and reusable UI sections.

### Benefits:
- Modular development
- Smooth GSAP integration
- Reusable animation logic
- Responsive state-driven UI
- Optimized rendering performance

## 🎨 Tailwind CSS
Tailwind CSS is a utility-first CSS framework that enables rapid and modern UI development directly through utility classes.

### Advantages:
- Fast styling workflow
- Fully responsive layouts
- Easy customization
- Clean and maintainable styling

## ⚡ Vite
Vite is a lightning-fast build tool and development server used for optimal development performance.

### Features:
- Instant hot module replacement
- Fast startup times
- Optimized production builds
- Smooth development experience for animation-heavy projects

Add immersive depth using smooth parallax effects tied to scroll movement.
